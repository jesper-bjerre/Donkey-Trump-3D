1: # Donkey Trump 3D Constitution
2: 
3: ## Core Principles
4: 
5: ### I. Native iPhone Play Comes First
6: 
7: The product MUST remain a native 3D arcade game with iPhone as its primary acceptance target.
8: Starting, restarting and playing installed game content MUST work without a backend connection.
9: Optional online features MUST load asynchronously, have finite user-visible deadlines, and leave
10: navigation usable while loading or failing. A late response MUST NOT interrupt a newer game or
11: change a different run's result. Network or storage work MUST NOT block the render loop or UI thread.
12: 
13: New or changed player-facing screens MUST work in landscape with safe areas, readable text and
14: reachable actions. Applicable menu/list controls MUST support VoiceOver and larger text. Changes
15: MUST preserve the existing Reduce Motion, sound and haptics settings unless the feature explicitly
16: changes their behaviour. These rules keep short play sessions usable on the baseline iPhone.
17: 
18: ### II. Simple Components and Explicit Ownership
19: 
20: Gameplay rules, scoring, collision logic and run transitions MUST remain testable independently of
21: SceneKit, SwiftUI and networking. Rendering presents simulation state; UI presents player actions
22: and results. Cross-thread state transfers MUST use snapshots or an explicit synchronization boundary;
23: new UI state MUST have a defined main-thread/main-actor owner.
24: 
25: The backend default is one small ASP.NET Core service in `src/backend`, using built-in platform
26: facilities and a separate test project when needed. Additional services, stores, frameworks or
27: architectural layers MUST have a feature-level justification explaining the requirement they solve
28: and why the existing structure is insufficient. Package versions and runtime baselines belong in
29: project files and feature plans, rather than being frozen permanently in this constitution.
30: 
31: Each state has a clear owner: the app owns local gameplay and its personal best; the backend owns
32: validation, ordering and persistence of shared rankings. Accepting a client-reported score MUST NOT
33: be described as proof of genuine gameplay. Simplicity does not remove these ownership boundaries.
34: 
35: ### III. Correct Shared Data and Bounded Failures
36: 
37: Shared read-modify-write state MUST use storage-enforced concurrency control that works across
38: multiple service instances. An in-process lock alone is insufficient. A conflict retry MUST read
39: current state and recompute the result; unconditional overwrite MUST NOT be a fallback. Duplicate
40: submissions MUST use a stable result identity, with the supported deduplication scope documented.
41: 
42: Remote operations MUST define deadlines, cancellation behaviour, retry conditions and finite retry
43: limits. A potentially committed write with a lost acknowledgement MUST be reported as unconfirmed;
44: retry behaviour MUST NOT imply that a failed response proves no save occurred. Missing, corrupt or
45: unavailable storage MUST NOT silently become an empty replacement. Tests MUST cover these distinctions
46: when shared persistence is introduced or changed.
47: 
48: Local personal-best data MUST survive remote failures. Cached results MUST be identifiable as stale
49: and MUST NOT establish fresh qualification or confirmed publication. For the agreed highscore v1,
50: a failed qualification or submission MUST NOT create an automatic, deferred or next-launch upload.
51: 
52: ### IV. Original Content and Deliberate Data Use
53: 
54: Game models, textures, animation and audio MUST remain original project material or have documented
55: permission compatible with their use. Copied Nintendo/Donkey Kong assets MUST NOT replace the
56: project's procedural characters or synthesized soundtrack. References to the original game's feel
57: are design inspiration, not authorization to copy its assets. Player copy MUST preserve the original
58: parody/no-affiliation description.
59: 
60: Public name/score publication MUST require an explicit player action and explain what is public.
61: Data collection and logs MUST be limited to the feature's documented purpose; diagnostics MUST NOT
62: record secrets, full submission bodies or player names. Storage credentials MUST stay out of the
63: app, repository and logs. Public service traffic MUST use HTTPS; local development exceptions MUST
64: remain isolated from release configuration. Azure-hosted storage access MUST use managed identity
65: with permissions scoped to the required data resources.
66: 
67: Privacy/help copy MUST match implemented data flows. A new account, analytics, advertising or
68: tracking capability MUST be an explicit product-scope change, never an incidental dependency.
69: 
70: ### V. Evidence Before Completion Claims
71: 
72: Changed gameplay rules, persistence, concurrency, retry and cancellation behaviour MUST have
73: repeatable checks for their observable outcomes and relevant failure cases. Use deterministic
74: inputs, clocks or service/storage substitutes where timing and randomness would hide defects.
75: Cross-component contracts MUST be checked at their boundaries; a test that only mirrors an
76: implementation detail is not sufficient evidence for the player's requirement.
77: 
78: Verification MUST be proportional to the change. Run the affected build/tests and relevant existing
79: regression checks; documentation-only edits need document validation, not an unrelated full build.
80: Device-dependent claims, including physical silent-switch behaviour, touch usability and sustained
81: performance, MUST be backed by checks on the relevant physical device before release acceptance.
82: A simulator pass MUST NOT be presented as physical-device evidence.
83: 
84: Reports and documentation MUST distinguish planned, implemented, tested and deployed behaviour,
85: identify what was actually checked, and record material limitations. Test instructions or a scaffold
86: MUST NOT be reported as a passing feature. Historical results MUST retain their date/context rather
87: than silently becoming evidence for a newer build.
88: 
89: ## Product and Technology Boundaries
90: 
91: - The current app baseline is Swift, SceneKit and SwiftUI, iOS 26+, landscape, with iPhone 13 as the
92:   reference device for acceptance. iPad is enabled in the project but needs its own evidence before
93:   iPad release-readiness claims. A platform or rendering-engine change requires an explicit design
94:   decision and appropriate regression coverage.
95: - Game content remains bundled for offline play. The imported 2D/browser project is a reference,
96:   not the deployment architecture. Player-facing copy and repository product documentation remain
97:   in English unless localization is explicitly scoped.
98: - In-game Sound controls game audio. With Sound enabled and audible output volume, physical silent
99:   mode MUST NOT suppress it; the in-game mute setting MUST silence active game audio. Intro skip or
100:   exit MUST stop intro audio without playing queued effects afterward.
101: - The agreed online extension is a global all-time top 100 of completed runs, without login or
102:   server-verified replays. Failed publication leaves the local personal best; no offline submission
103:   queue is in scope. Exact tie, name, scrolling, timeout and endpoint rules belong in its feature spec
104:   and contracts, not as duplicated constants here.
105: - The initial backend design uses ASP.NET Core Minimal APIs and private Azure Blob Storage with
106:   conditional writes. Hosting and storage choices MUST document expected traffic, contention and
107:   running-cost tradeoffs. Use supported stable platform releases and serviced production runtimes;
108:   adding infrastructure requires a concrete feature or measured operational need.
109: - Accounts, online multiplayer, cloud-saved runs, purchases, advertising and extra languages are not

5:     static func validScore(_ score: Int) -> Bool { score >= 0 && score <= 2_147_483_600 && score % 100 == 0 }

7:         guard !input.unicodeScalars.contains(where: {
8:             [.control, .lineSeparator, .paragraphSeparator].contains($0.properties.generalCategory)
9:         }) else { return nil }
10:         let name = input.precomposedStringWithCanonicalMapping.trimmingCharacters(in: .init(charactersIn: "\u{0020}\u{00a0}\u{1680}\u{2000}\u{2001}\u{2002}\u{2003}\u{2004}\u{2005}\u{2006}\u{2007}\u{2008}\u{2009}\u{200a}\u{202f}\u{205f}\u{3000}"))

12:               name.unicodeScalars.contains(where: { !$0.properties.isWhitespace && $0.properties.generalCategory != .format }) else { return nil }

25:               (1...2_147_483_647).contains(run.levelReached), let name = HighscoreRules.name(name) else {

39: struct HighscoreEntry: Codable, Sendable, Equatable, Identifiable {
40:     let entryId: UUID
41:     let rank: Int
42:     let displayName: String
43:     let score: Int
44:     var id: UUID { entryId }
45: }

47: enum HighscoreOutcome: String, Codable, Sendable { case ranked, notQualified }
48: 
49: struct HighscoreSnapshot: Codable, Sendable, Equatable {
50:     let entries: [HighscoreEntry]
51:     let revision: String
52:     let fetchedAtUtc: Date
53:     var outcome: HighscoreOutcome?
54:     var entryId: UUID?
55:     var rank: Int?
56: 
57:     func validate(submission: Bool = false) throws {
58:         guard entries.count <= 100, !revision.isEmpty, revision.count <= 256,
59:               Set(entries.map(\.id)).count == entries.count else { throw HighscoreServiceError.invalidResponse }
60:         var previousScore = Int.max
61:         for (index, entry) in entries.enumerated() {
62:             guard entry.id != HighscoreRules.zeroID, entry.rank == index + 1,
63:                   HighscoreRules.validScore(entry.score), entry.score <= previousScore,
64:                   HighscoreRules.name(entry.displayName) == entry.displayName else { throw HighscoreServiceError.invalidResponse }
65:             previousScore = entry.score
66:         }
67:         if submission {
68:             switch outcome {
69:             case .ranked:
70:                 guard let entryId, let rank, entries.contains(where: { $0.id == entryId && $0.rank == rank }) else { throw HighscoreServiceError.invalidResponse }
71:             case .notQualified:
72:                 guard entries.count == 100, entryId == nil, rank == nil else { throw HighscoreServiceError.invalidResponse }
73:             case nil: throw HighscoreServiceError.invalidResponse
74:             }
75:         } else if outcome != nil || entryId != nil || rank != nil { throw HighscoreServiceError.invalidResponse }
76:     }

79:         HighscoreRules.validScore(score) && (entries.count < 100 || score > (entries.last?.score ?? Int.max))
80:     }

4: protocol InstallationCredentialProviding: Sendable {
5:     func authorization() async throws -> String
6: }
7: 
8: actor InstallationCredentialStore: InstallationCredentialProviding {
9:     static let shared = InstallationCredentialStore()
10:     private let file: URL
11:     init(file: URL? = nil) {
12:         self.file = file ?? FileManager.default.urls(for: .applicationSupportDirectory, in: .userDomainMask)[0]
13:             .appendingPathComponent("Moderation/installation-secret")
14:     }
15:     func authorization() throws -> String {
16:         do { return try readOrCreate() }
17:         catch { throw HighscoreServiceError.credentialUnavailable }
18:     }
19:     private func readOrCreate() throws -> String {
20:         let manager = FileManager.default
21:         let bytes: Data
22:         if manager.fileExists(atPath: file.path) {
23:             bytes = try Data(contentsOf: file)
24:             guard bytes.count == 32 else { throw HighscoreServiceError.credentialUnavailable }
25:         } else {
26:             try manager.createDirectory(at: file.deletingLastPathComponent(), withIntermediateDirectories: true)
27:             var random = [UInt8](repeating: 0, count: 32)
28:             guard SecRandomCopyBytes(kSecRandomDefault, random.count, &random) == errSecSuccess else { throw HighscoreServiceError.credentialUnavailable }
29:             bytes = Data(random)
30:             try bytes.write(to: file, options: [.atomic, .completeFileProtectionUntilFirstUserAuthentication])
31:         }
32:         // A failure here also fails online writes; never rotate an existing secret.
33:         var url = file
34:         var values = URLResourceValues(); values.isExcludedFromBackup = true
35:         try url.setResourceValues(values)
36:         return "Bearer " + bytes.base64EncodedString().replacingOccurrences(of: "+", with: "-")
37:             .replacingOccurrences(of: "/", with: "_").replacingOccurrences(of: "=", with: "")
38:     }
39: }

11: final class URLSessionHighscoreService: HighscoreService, @unchecked Sendable {
12:     private let configuration: HighscoreConfiguration
13:     private let credential: any InstallationCredentialProviding
14:     private let session: URLSession
15:     init(configuration: HighscoreConfiguration, sessionConfiguration: URLSessionConfiguration? = nil, credential: any InstallationCredentialProviding = InstallationCredentialStore.shared) {
16:         self.configuration = configuration; self.credential = credential
17:         let transport = sessionConfiguration ?? .ephemeral
18:         transport.waitsForConnectivity = false
19:         transport.timeoutIntervalForRequest = 8
20:         transport.timeoutIntervalForResource = 8
21:         transport.urlCache = nil; transport.httpCookieStorage = nil
22:         transport.requestCachePolicy = .reloadIgnoringLocalAndRemoteCacheData
23:         session = URLSession(configuration: transport, delegate: HighscoreRedirectPolicy(), delegateQueue: nil)
24:     }
25:     deinit { session.invalidateAndCancel() }
26:     func read() async throws -> HighscoreSnapshot { try await execute(nil) }
27:     func submit(_ submission: HighscoreSubmission) async throws -> HighscoreSnapshot { try await execute(submission) }
28: 
29:     private func execute(_ submission: HighscoreSubmission?) async throws -> HighscoreSnapshot {
30:         var request = URLRequest(url: configuration.endpoint)
31:         request.httpMethod = submission == nil ? "GET" : "POST"
32:         request.setValue("application/json", forHTTPHeaderField: "Accept")
33:         request.setValue("no-store", forHTTPHeaderField: "Cache-Control")
34:         if let submission {
35:             request.setValue(try await credential.authorization(), forHTTPHeaderField: "Authorization")
36:             request.setValue("application/json", forHTTPHeaderField: "Content-Type")
37:             request.httpBody = try JSONEncoder().encode(submission)
38:         }
39:         do {
40:             let (bytes, response) = try await session.bytes(for: request)
41:             guard let response = response as? HTTPURLResponse, response.url == configuration.endpoint else { throw HighscoreServiceError.invalidResponse }
42:             var data = Data()
43:             for try await byte in bytes {
44:                 guard data.count < 256 * 1024 else { bytes.task.cancel(); throw HighscoreServiceError.invalidResponse }
45:                 data.append(byte)
46:             }
47:             if response.statusCode == 200 {
48:                 guard response.mimeType == "application/json" else { throw HighscoreServiceError.invalidResponse }
49:                 let result = try HighscoreSnapshot.decode(data, submission: submission != nil)
50:                 if let submission, result.outcome == .ranked {
51:                     guard result.entryId == submission.submissionId,
52:                           let row = result.entries.first(where: { $0.id == submission.submissionId }),
53:                           row.score == submission.score, row.displayName == submission.displayName else { throw HighscoreServiceError.invalidResponse }
54:                 }
55:                 if let submission, result.outcome == .notQualified {
56:                     guard !result.qualifies(submission.score),
57:                           !result.entries.contains(where: { $0.id == submission.submissionId }) else { throw HighscoreServiceError.invalidResponse }
58:                 }
59:                 return result
60:             }
61:             guard response.mimeType == "application/problem+json",
62:                   let problem = try? JSONDecoder().decode(HighscoreProblem.self, from: data), problem.status == response.statusCode else {
63:                 throw HighscoreServiceError.invalidResponse
64:             }

61:     init(configuration: HighscoreConfiguration, credential: any InstallationCredentialProviding = InstallationCredentialStore.shared,
62:          sessionConfiguration: URLSessionConfiguration? = nil) {
63:         self.configuration = configuration; self.credential = credential

65:         transport.waitsForConnectivity = false; transport.timeoutIntervalForRequest = 8; transport.timeoutIntervalForResource = 8
66:         transport.urlCache = nil; transport.httpCookieStorage = nil; transport.requestCachePolicy = .reloadIgnoringLocalAndRemoteCacheData

68:     }

71:     func status(_ id: UUID) async throws -> ReportReceipt { try await execute(report: nil, id: id) }
72:     private func execute(report: ReportSubmission?, id: UUID) async throws -> ReportReceipt {
73:         let endpoint = report == nil ? configuration.reportEndpoint.appendingPathComponent(id.uuidString.lowercased()) : configuration.reportEndpoint
74:         var request = URLRequest(url: endpoint)
75:         // Credential failures occur before any possible network write.
76:         request.setValue(try await credential.authorization(), forHTTPHeaderField: "Authorization")
77:         request.httpMethod = report == nil ? "GET" : "POST"
78:         request.setValue("application/json", forHTTPHeaderField: "Accept")
79:         request.setValue("no-store", forHTTPHeaderField: "Cache-Control")
80:         if let report {
81:             request.setValue("application/json", forHTTPHeaderField: "Content-Type")
82:             request.httpBody = try JSONEncoder().encode(report)
83:         }
84:         do {
85:             let (bytes, raw) = try await session.bytes(for: request)
86:             guard let response = raw as? HTTPURLResponse, response.url == endpoint else { throw HighscoreServiceError.invalidResponse }
87:             var data = Data()
88:             for try await byte in bytes { guard data.count < 16_384 else { bytes.task.cancel(); throw HighscoreServiceError.invalidResponse }; data.append(byte) }
89:             if (report == nil && response.statusCode == 200) || (report != nil && [200, 201].contains(response.statusCode)) {
90:                 guard response.mimeType == "application/json" else { throw HighscoreServiceError.invalidResponse }
91:                 let receipt = try HighscoreSnapshot.decoder().decode(ReportReceipt.self, from: data)
92:                 try receipt.validate()
93:                 guard receipt.reportId == id || report != nil && receipt.alreadyPending == true else { throw HighscoreServiceError.invalidResponse }
94:                 return receipt
95:             }
96:             guard response.mimeType == "application/problem+json", let problem = try? JSONDecoder().decode(HighscoreProblem.self, from: data), problem.status == response.statusCode else { throw HighscoreServiceError.invalidResponse }
97:             throw HighscoreServiceError.rejected(problem)
98:         } catch HighscoreServiceError.rejected(let problem) { throw HighscoreServiceError.rejected(problem) }
